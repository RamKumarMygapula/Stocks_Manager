# Stock Manager

A full-stack stock portfolio management application.

## Tech Stack

- FastAPI
- React
- TypeScript
- Material UI
- React Query
- Recharts

## Features

- Portfolio Dashboard
- CRUD Operations
- Portfolio Insights
- Sector Allocation
- Stock Details Drawer
- Live Market Data

## Backend

cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload

## Frontend

cd frontend

npm install

npm run devc
